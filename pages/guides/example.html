歡迎使用靜態頁面系統

這是一個範例靜態頁面，展示了如何使用設計系統來建立美觀、一致的靜態內容。

主要特點

  • 完全獨立：每個靜態頁面都是獨立的，沒有指向其他頁面的連結
  • 設計一致：繼承主應用的 design-system.css，確保視覺風格統一
  • 隱私保護：管理檔案不會被推送到 GitHub，訪客無法發現其他頁面
  • 易於使用：只需將完整的 HTML 檔案放入對應類別目錄即可

重要提示

這個頁面使用了主應用的設計系統，您可以直接使用所有的 CSS 變數和樣式組件。請參考 design-system.css 瞭解更多可用的設計 tokens。

如何新增靜態頁面

  1. 將您的完整 HTML 檔案放入對應的類別目錄（例如 pages/guides/）
  2. 在本地的 pages/_registry.js 中註冊頁面資訊（僅本地使用，不會推送到 GitHub）
  3. 透過本地的 pages/index.html 列表頁預覽和管理所有頁面
  4. 提交到 Git 時，只有靜態頁面本身會被推送，管理檔案保持在本地

使用設計系統

您可以使用以下的設計系統元素：

  • 顏色變數：var(--color-primary-600)、var(--color-neutral-700) 等
  • 字體大小：var(--font-size-xl)、var(--font-size-lg) 等
  • 間距：var(--spacing-4)、var(--spacing-8) 等
  • 圓角：var(--border-radius-md)、var(--border-radius-lg) 等
  • 陰影：var(--shadow-sm)、var(--shadow-lg) 等
